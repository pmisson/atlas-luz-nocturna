# Montserrat

**Clasificación:** guia

El Physical Development Plan for North Montserrat 2012–2022 recomienda que las guías de planificación minimicen contaminación lumínica y ruido en periodos críticos de anidación de tortugas marinas. La web oficial sigue listando el plan como activo, pero el horizonte temporal venció y no se verificó adopción de límites técnicos exigibles.

**Ámbito:** Planeamiento de North Montserrat, especialmente playas y periodo de nidificación

**Cautela jurídica:** No convertir 'planning guidelines will minimise' en una prohibición general; distinguir vigencia del registro y horizonte 2012–2022.
