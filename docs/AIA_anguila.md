# Anguila

**Clasificación:** guia

El Plan de Gestión del Sistema de Parques Marinos recomienda expresamente introducir reglas de iluminación de playas para proteger tortugas marinas. El Sustainable Tourism Master Plan 2010–2020 repite la necesidad de regularla. No se ha identificado en estas fuentes una regulación de alumbrado ya aprobada.

**Ámbito:** Recomendaciones para playas y parques marinos

**Cautela jurídica:** Una recomendación para introducir legislación acredita una laguna regulatoria histórica, no prueba ausencia actual absoluta.
