# Guam

**Clasificación:** guia

Documentos oficiales de proyectos federales incluyen medidas para evitar la desorientación de tortugas por iluminación nocturna, como limitar trabajos de noche, dirigir luminarias y usar espectros apropiados. Son condiciones o buenas prácticas de proyecto, no una regulación general de Guam acreditada.

**Ámbito:** Proyectos y hábitats costeros (territorio de EE. UU.)

**Cautela:** Comprobar caso por caso si la medida está incorporada a permiso vinculante.
