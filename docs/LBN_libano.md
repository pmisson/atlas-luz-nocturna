# Líbano — legislación sobre contaminación lumínica

**Ámbito:** Certificación ARZ de edificios participantes
**Categoría:** Directriz o estándar no general
**Evidencia:** Manual de ARZ identifica expresamente criterio como opcional
**Revisión:** 23-11-2026

## Síntesis
El sistema ARZ de calificación ambiental de edificios incorpora el crédito opcional Si-3.1 'Night Light Pollution', para reducir luz ascendente y deslumbramiento en propiedades vecinas y proteger fauna nocturna.

## Cautelas
No equivalente a ley nacional de prevención de contaminación lumínica; verificar requisitos contractuales de cada proyecto.

## Referencias

Minimizar luz ascendente, intrusión luminosa y deslumbramiento.. El criterio del propio manual indica Optional.

## Medidas
- **Líbano ARZ Si-3.1: iluminación nocturna de edificios**: Crédito opcional para contener emisión ascendente, deslumbramiento y luz intrusa.. **Fuerza:** Certificación voluntaria. **Cautela:** El documento dice Optional; no legalidad nacional.
