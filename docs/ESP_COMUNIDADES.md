# Legislacion subnacional espanola (corte 19-XI-2026)

Se incluyen las 17 comunidades autonomas y las dos ciudades autonomas, sin computarlas como paises. Un resultado pendiente no equivale a ausencia normativa. Revisar boletines oficiales consolidados.
